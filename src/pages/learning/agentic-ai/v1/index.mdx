Agentic AI v1 is Kavriq's first structured path for learning how agent systems are built and how they behave in production.

Use the foundations track when you want the sequential curriculum. Use the engineering track when you want the systems-level production perspective.

---

## Foundations

The 12-part core curriculum for learning the building blocks of modern agent systems: agent loops, cognitive architecture, planning, tools, memory, multi-agent systems, guardrails, evaluation, runtime internals, and capstone projects.
